- **What is not claimed.** No arrow geometry: the shapes carry placement data in the markup, and it is neither reproduced nor turned into a statement about the drawing, because the extracted text carries none. No source page render, no screenshot, no device-display verification. No fourth stage, no storage stage, and nothing merged from the six-stage cycle at lines 149-163.
