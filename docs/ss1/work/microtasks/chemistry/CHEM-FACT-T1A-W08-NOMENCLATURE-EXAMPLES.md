## Findings register
| Source locator | Source wording / issue | Reference terminology / finding |
|---|---|---|
| 1537-1541 | Acid-radical names and spelling “Dioxonitratei(iii)” | The source appears to intend the nitrite ion, NO₂⁻, which is also called nitrate(III) in systematic oxoanion nomenclature. “Dioxonitrate(III)” may be a school-systematic name, but the appended “i” is a typographical defect. The exact adopted naming system should be stated consistently. |
| 1545 | KNO₃ named with oxidation numeral (iv) | In KNO₃, potassium is +1, oxygen is −2 and nitrogen is +5. The common name is potassium nitrate; under the systematic oxoanion scheme it is potassium nitrate(V) / potassium trioxonitrate(V), not (IV). |
| 1551 | NaSO₄ paired with sodium tetraoxosulphate(VI) | Sodium sulfate is Na₂SO₄, not NaSO₄, because two Na⁺ ions balance one SO₄²⁻ ion. The source formula is charge-unbalanced as written. Preserve it and record the correction separately. |
| 1553-1567 | Roman-numeral oxidation-state names | Oxidation numerals must match the central atom's oxidation state. In nitrate, N is +5; in nitrite, N is +3; in sulfate, S is +6. Do not confuse the oxidation number of an atom with the ionic charge of the whole polyatomic ion. |
| 1603-1623 | Tertiary/quaternary compound table and weekend distractors FeO₃ and KU | FeO₃ is not a standard common iron oxide formula; common binary oxides include FeO (iron(II) oxide) and Fe₂O₃ (iron(III) oxide). “KU” is not a valid neutral binary formula for the common K⁺ cation and a monatomic anion; its intended species cannot be inferred from the distractor alone. Keep both as source assessment options and do not silently replace. |
