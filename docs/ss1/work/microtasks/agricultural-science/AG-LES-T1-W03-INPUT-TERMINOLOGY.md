## Lesson body

Week 3 Terminology Supplement: Herbicide and Related Pesticide Terms

This supplement explains the terms needed for the Week 3 weekend question about the substance used to control weeds. It provides definitions only. It does not give product recommendations, application instructions, rates, doses, mixing directions or handling advice.

## 1. Pesticide

A pesticide is a broad term for a substance or mixture intended to prevent, destroy, repel or control a pest. Pesticides include several groups, such as herbicides, insecticides, fungicides and rodenticides. Some pesticide products may be chemical or biological.

## 2. Herbicide

A herbicide is a type of pesticide used to destroy or control unwanted plants, especially weeds. It is the specific term for a weed-control product.

## 3. Weedicide

Weedicide is another name for a herbicide. Both terms refer to an agent used to control weeds. It is not a different target group from herbicide.

## 4. Insecticide

An insecticide is a type of pesticide used to kill or control insects. It targets insects, not weeds.

## 5. Other Related Terms

- Fungicide: a pesticide used to control fungi.
- Rodenticide: a pesticide used to control rodents such as rats and mice.

## 6. Answering the Week 3 Multiple-Choice Question

The source asks which chemical is used to destroy weeds and offers both **herbicide** (option A) and **weedicide** (option C). These are synonyms. Therefore, both A and C are correct in meaning. “Herbicide” is the standard technical term, but “weedicide” is also a recognised name for a weed-control agent. The question does not have one unique correct option as printed. A fair answer key should accept A or C; if only one option is to be correct in a future version, the assessment writer should replace one of the duplicate choices.

Remember: pesticide is the broad group; herbicide/weedicide controls weeds; insecticide controls insects. This supplement is terminology teaching only and gives no instructions for selecting, buying, mixing, applying, storing or handling pesticide products.
