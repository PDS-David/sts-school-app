# SS1 Mathematics — self-generated four-figure logarithm and antilogarithm tables

**Purpose:** This original reference table is provided for the SS1 Mathematics logarithm lessons. It is generated from the definitions of common logarithm and antilogarithm; it is not copied from a commercial mathematical-table book. Values are rounded for four-figure classroom work.

## How to use the common logarithm table

1. Write the number as a × 10^k with 1 ≤ a < 10. The integer k is the characteristic; the table gives the mantissa log10(a).
2. Use the first two significant digits for the row and the third significant digit for the main column.
3. Use the mean-difference (MD) column for the fourth significant digit; add it to the main mantissa.
4. For a number greater than 1, the characteristic is the number of digits before the decimal point minus one. For a number between 0 and 1, use bar-characteristic notation; the bar applies to the integer characteristic only.

**Example:** For 8615 = 8.615 × 10^3, row 86 and column 1 give the mantissa for 8.61; MD 5 refines it to about 0.9353. Add characteristic 3: log10(8615) ≈ 3.9353.

## How to use the antilogarithm table

1. Keep only the mantissa of the logarithm for the table lookup; use the characteristic afterwards to place the decimal point.
2. The row gives the first two decimal places of the mantissa; the main column gives the third decimal place; the MD column gives the fourth decimal place.
3. The table gives a number between 1 and 10. Multiply by 10 raised to the characteristic to obtain the original number.

**Example:** For antilog 3.5680, row 0.56 and column 8 give about 3.698; characteristic 3 gives about 3.698 × 10^3 = 3698.
