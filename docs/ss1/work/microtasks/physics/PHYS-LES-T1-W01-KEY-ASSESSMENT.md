## Proposed marking total: 44 marks

The source gives no marks. The following is a suggested scheme so that the key has an exact total.

### EVALUATION — page 3 (6 marks)

1. **What is Physics?** (2 marks)
   - Physics is the branch of natural science that studies matter, energy, motion and forces, and the interactions governing natural phenomena. Award 1 mark for the subject area and 1 for the core scope (matter/energy/motion/forces/interactions).
2. **State the steps involved in the scientific method.** (4 marks)
   - Proposed answer: observation; identify/question the problem; formulate a testable hypothesis; plan and perform an experiment; record and analyse data; draw a conclusion; communicate/revise the explanation.
   - Award 1 mark each for any four correctly ordered stages, with the hypothesis and testing stages represented.
   - **Scope warning:** the source asks this question but does not teach the scientific method in its Week One body. This is an independently proposed answer, not a source-derived lesson. Teacher must approve it or withdraw/reassign the question before final use.

### WEEKEND ASSIGNMENT — page 6 (7 marks)

1. **(d) Mass** — mass is a base quantity; area, thrust and pressure are derived.
2. **(d) kg** — kilogram is an SI base unit.
3. **(b) Work** — work and energy share the joule.
4. **(d) Ohm** — the ohm is a derived SI unit.
5. **Defective as printed.** Tension, impulse and upthrust are all derived units; distance is a base quantity. There is no single correct answer to “Which is a derived unit?” Suggested replacement: “Which is a fundamental quantity/unit?” with distance/metre as the only correct option.
6. **(c) kg, m, sec** — intended mechanical base units; use the correct SI symbol `s` for second.
7. **(b) I, II and III only** — area, thrust and pressure are derived; mass is fundamental.
