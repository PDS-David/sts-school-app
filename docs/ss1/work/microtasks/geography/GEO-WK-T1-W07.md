## Findings and corrections
- Corrected the source's mantle thickness typo from 290 km to about 2,900 km.
- Corrected the description of the mantle: most mantle rock is solid and deforms/flows slowly over geological time; it is not a semi-liquid ocean of magma.
- Corrected the core description: the outer core is liquid; the inner core is solid. The core is mainly iron-nickel metal. Inner-core temperature is about 5,400°C, not 2,000°C.

- Clarified that NIFE refers to nickel and iron elements, not minerals.
