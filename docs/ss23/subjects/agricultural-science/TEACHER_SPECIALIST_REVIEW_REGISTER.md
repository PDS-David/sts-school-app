## How to use this register

This register transcribes the package's 47 open items into one review surface. It is intended for the Agriculture subject lead, relevant specialists and owner. The `Required decision/action` column states what is still needed; it is not an assertion that the issue has been resolved.

For every item, the reviewer should record:
- decision: APPROVE / AMEND / REJECT / SOURCE NEEDED / RIGHTS NEEDED;
- exact evidence reviewed (source page, reference, lab method or rights grant);
- amendment required, if any;
- reviewer name/role and date; and
- approval record identifier for the repository.

Do not sign on another person's behalf. A source correction supported by an external reference is not automatically a teacher approval. A technical test is not an educational review. Keep every blocker open until its stated evidence and approval are recorded and the package is updated and revalidated.
