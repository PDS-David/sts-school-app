## Reconciliation findings and cautions

1. The extracted source contains **96 assessment/assignment blocks**. This register supplies source locators for comparison with the package; it does not assert that every source prompt is represented in the 195 package practice records.
2. The existing package inventory records 195 practice entries: 128 tagged `ORIGINAL_SOURCE` and 67 tagged `AUTHORED_SUPPLEMENT`. All 45 Second- and Third-Term package entries are supplements, not source-verbatim questions. Do not relabel these as original-source items.
3. Original-source entries still require a prompt-by-prompt match to this register and, where an assignment points to a textbook/WAEC PAQ, the referenced edition and exact question must be verified before transcription or answer certification.
4. The Third-Term class activity at line 575 has an apparently interleaved input/output table in the text extraction (including the word “Egg” in the row labelled “Feeds”). The source layout must be inspected before reconstructing its data or graph.
5. Third-Term farm-records/accounts teaching appears between the economics material and animal-nutrition material. Its source body is present despite the missing distinct Week 7–8 heading noted in the archive verification. Preserve the body; do not invent a missing heading as evidence.
6. The package's structural checks (unique IDs, marking totals and locator fields) do not establish that a question/answer is factually correct or accurately transcribed.
7. No source-dependent blocker is closed by this inventory. It does not approve content, clear image rights, authorize a practical, or enable delivery.
