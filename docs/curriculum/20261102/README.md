## How to use

Copy the entire chosen file from `prompts/` into the assigned agent's chat, or give it the repository URL of that file. Each contains the execution contract; no secret previous chat or unpublished patch is required. One prompt = one bounded assignment. You approve each next assignment. Source/decision/verification gates are explicit; the agent must ask you when it reaches them and continue independent work. A prompt cannot guarantee genuine absent material, a rights grant, a device or credentials will magically exist.

Start with the21 S-subject prompts independently (one worker per subject), and J1/J3/J4/J5/P1 for JSS3 decisions serially where shared files overlap. S-DECISION handles one blocked item at a time. I1–I7 are actual SS1 integration implementation, sequential for shared code. L1/L2 and N1 are separate receipt/scope tracks, not authority to re-audit all classes. Never run future verification/release just because its prompt exists.

## Completion definitions

Teacher-certified/learner competence requires genuine corresponding observations. These are separate, and none is inferred from a green PR.
