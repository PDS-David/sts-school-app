# JSS3 teaching sequence — ordering contract and teacher schedule (16 Oct 2026)

Scope: read-only analysis of `master` at `7894996`. No app, schema, importer or database change.

## Contract found in code
1. `GET /topics` sorts by `order_index` (NULLS LAST) — `backend/src/routes/learning.ts`.
2. Student unlock chain follows `order_index` within subject + class + term: topic N opens only after topic N-1 is **passed**; the first topic needs the term PIN — `POST /topics/:id/complete`, same file.
3. Importer assigns `order_index` 1..n per class/subject/term in file order and verifies existing rows by `[bucket, orderIndex]` — `backend/src/db/ingestTopics.ts`.
4. Asset attachment targets rows by `order_index` with a title guard — `backend/src/db/attachTopicAssets.ts`. Supplement asset targets (e.g. order 12) depend on append order.
5. Supplements are built with `orderIndex: 0` and receive appended numbers after the originals — `backend/src/db/jss3Supplements.ts`.

## Consequences
- Appended supplements sit after the last original topic of their term. A student cannot open any supplement until passing every original topic before it, including any revision or examination rows that are topics. Whether such rows exist in each bucket needs the original row bodies (not in Git).
- A teacher schedule can order *teaching*; it cannot change *student unlock order*.
- Inserting supplements mid-sequence would renumber originals and break the audited-sequence check, asset targets and existing unlock positions.

## Options
| Option | Change | Risk |
|---|---|---|
| A. Keep append + teacher schedule (current) | none to code | Students meet supplements last |
| B. Add a per-bucket schedule position used for display and the unlock chain | schema migration, route, mobile screen, importer, tests | Touches production DB and student locks; needs owner decision |
| C. Insert and renumber | importer + assets | Rejected: breaks protected identities |

Recommendation: A now. Take B to the owner as a decision only if the append position is unacceptable in the app view.

## Teacher schedule
`TEACHER_SCHEDULE_SUPPLEMENTS.csv` (generated by `scripts/jss3/build_teacher_schedule.py`) lists each of the 41 supplements with its append `order_index`, originals count in its bucket, and the earliest scheme week or list item recorded in the R9 register or WIDER_WORKSTREAMS.
- Anchors use only gaps from the supplement's own term. Where a supplement serves several weeks, the earliest is given.
- `scheme_list_item` (Basic Technology, Mathematics) is a list position, not a week.
- SUP-TKD has no anchor: its gap TK-01 is Third-Term. The owner or teacher chooses the week.
- Every row says to teach before the term assessment week. Not verified against the actual week of each term's examination.
