# SS1 French dialogue audio

These recordings are synthetic French speech generated from the original eight-turn classroom dialogue in the SS1 French curriculum.

- `SS1_French_Dialogue_standard.mp3`: standard pace.
- `SS1_French_Dialogue_slow.mp3`: slower practice pace.

## Voice and attribution

Generated with Piper TTS using the two-speaker `fr_FR-upmc-medium` French voice model:
- Speaker 0 (Jessica) reads Ada's turns.
- Speaker 1 (Pierre) reads the librarian's turns.
- Voice dataset: UPMC / MaryTTS UPMC Pierre data, licensed under Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0): https://creativecommons.org/licenses/by-sa/4.0/
- Dataset source: https://github.com/marytts/upmc-pierre-data
- Voice model catalogue: https://huggingface.co/rhasspy/piper-voices/tree/v1.0.0/fr/fr_FR/upmc/medium
- Speech engine: Piper TTS, https://github.com/OHF-Voice/piper1-gpl

The dialogue text is original classroom content. The audio is synthetic; it is not a human/native-speaker recording, not an official WAEC/NECO examination recording, and not a claim of native-speaker certification. Teacher review of pronunciation remains required before formal assessment use.
